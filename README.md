# A-Share Dual Moving Average Strategy Backtest

基于 Python 的 A 股双均线策略回测系统，使用 `akshare` 获取真实行情数据，模拟含手续费与印花税的实盘交易，并计算夏普比率、最大回撤、胜率等绩效指标。

## 📌 项目背景

本项目是我从计算机背景转向金融数据分析方向的**第一个实战项目**。目标是用 Python 完整实现一个策略回测流程，覆盖从数据获取、信号生成到绩效评估的全链路。

## 🛠️ 技术栈

- **Python 3.13.11**
- **akshare** — A 股历史行情数据获取
- **pandas / numpy** — 数据清洗与向量化计算
- **matplotlib** — 交易信号可视化

## 📈 策略逻辑

**双均线策略（Dual Moving Average）** 是最经典的趋势跟踪策略之一：

- **金叉买入**：当 5 日均线（MA5）上穿 20 日均线（MA20）
- **死叉卖出**：当 5 日均线下穿 20 日均线（MA20）

策略假设：短期均线代表近期价格动能，长期均线代表趋势方向。当短期动能向上突破长期趋势时，视为买入信号。

## 💰 交易成本模拟

为贴近实盘，回测中加入了以下成本：

| 成本类型 | 费率 | 说明 |
| :--- | :--- | :--- |
| 佣金 | 0.03% | 买卖双向收取 |
| 印花税 | 0.1% | 仅卖出时收取 |

> 初始资金：**500 万元**；最小交易单位：**100 股（1 手）**。

## 📊 绩效指标

| 指标 | 计算方式 | 含义 |
| :--- | :--- | :--- |
| **累计收益率** | `(总资产 / 初始资金) - 1` | 策略整体盈亏 |
| **夏普比率** | `(年化收益 - 无风险利率) / 年化波动率` | 每承担一单位风险获得的超额收益 |
| **最大回撤 (MDD)** | `max( (总资产 - 历史最高) / 历史最高 )` | 最坏情况下的亏损幅度 |
| **胜率** | `盈利交易数 / 总交易数` | 交易信号的准确性 |
| **盈亏比** | `总盈利 / 总亏损` | 盈利交易的收益覆盖亏损的能力 |

> 无风险利率假设为 **3%**，年化交易日按 **252 天** 计算。

## 🧠 策略思考与局限

- **趋势市有效，震荡市失效**：双均线是趋势跟踪策略，在单边行情中表现较好，但在横盘震荡中会产生大量假信号，吸引散户入场。
- **参数敏感性**：5/20 是经验参数，未必最优。后续可尝试网格搜索寻找更优参数组合。
- **未考虑滑点与流动性**：真实交易中，大额订单可能影响成交价格。
- **单一标的**：当前只回测单只股票，后续可扩展到多标的组合。


## 📊 参数敏感性分析 结果来自aks_use_entire.py
## 2026/09/11新增多设置几组参数以对比
对以下 5 组均线参数在同一区间（2025-01-01 ~ 2026-01-01，贵州茅台）进行回测：

| 参数组合 | 累计收益率 | 夏普比率 | 最大回撤 | 胜率 | 盈亏比 | 交易次数 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **MA5/MA20** | **-2.66%** | **-0.43** | **-12.13%** | **37.50%** | **0.79** | **8** |
| MA10/MA30 | -6.68% | -0.74 | -15.77% | 20.00% | 0.52 | 5 |
| MA5/MA60 | -6.11% | -0.99 | -9.78% | 0.00% | 0.00 | 4 |
| MA10/MA60 | -8.70% | -1.30 | -12.31% | 0.00% | 0.00 | 4 |
| MA20/MA60 | -4.40% | -0.75 | -10.67% | 50.00% | 0.20 | 2 |

**核心发现：**

1. **MA5/MA20 在本区间表现最优**：虽然仍亏损 2.66%，但回撤控制最好（-12.13%），胜率最高（37.5%），是 5 组中综合表现最好的。
2. **均线周期差过大反而有害**：MA5/MA60 和 MA10/MA60 胜率均为 0%，说明短期均线与长期均线周期差距过大时，长期均线的滞后性会导致信号严重滞后。
3. **MA20/MA60 胜率 50% 但盈亏比仅 0.20**：虽然赢了一半的交易，但赢的时候赚得少、亏的时候亏得多，说明长周期组合在震荡市中"赢得小、输得大"。
4. **样本量限制**：MA20/MA60 仅 2 次配对交易，统计意义有限，需扩大回测区间验证。
5. **参数选择与市场状态强相关**：结合 2023-2024 区间（下跌市）的回测结果，MA20/MA60 在下跌市中表现更好（+1.33%），而本区间（震荡市）中 MA5/MA20 更优。**不存在万能参数，后续可考虑加入趋势过滤（如 ADX）动态调整。**
